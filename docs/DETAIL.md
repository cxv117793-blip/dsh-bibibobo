# 哔哔啵啵朗读

用 [bibibobo](https://github.com/hakihakii/bibibobo) 的锯齿波小人声，把 DeepSeek Harness 的回复念出来。可以随时暂停、继续、结束。

## 用法

在任意会话里，输入框下方会多出一行控制条：

- **🔊 朗读** — 把最近一条已完成的回复念出来
- **⏸ 暂停 / ▶ 继续** — 暂停和续播，位置保留
- **⏹ 结束** — 立即停止并释放音频

朗读的永远是**最新一条已经完成的回复**。流式输出中的内容不会被读，避免念到一半又变。控制条在还没有任何回复时不会出现。

## 声音是怎么来的

不是录音，也不是 TTS 模型，是实时算出来的波形：

1. 一条抗混叠锯齿波当作声带；
2. 两个带通滤波器捏出口型，五种口型就是五对共振峰频率；
3. 一个汉字一声，一串英文或数字一声；每个字用哈希算出固定的音高和口型，所以同一个字永远是同一声；
4. 标点管语气：问号尾音上扬，感叹号整句升高，省略号整句压低。

两套声线都带过来了：大肥鱼（E5 G5 A5 B5 C6，共振峰 ×1.25）和路墨（D4 E4 G4 A4，共振峰 ×0.9）。

## 朗读前会清掉的 Markdown

代码块、行内代码、图片、链接地址、标题井号、引用符号、列表符号、强调记号都会被去掉，只留下能念的文字。链接保留文字、丢掉地址。这样一段带表格和代码的回复不会变成一长串符号。

回复超过 1200 字会截断，避免一次点击产生几分钟的音频。

## 已知边界

- 只读**纯文本**部分。带工具调用和思维链的回复，只念最终文字。
- 同一时间只能有一段朗读。点「朗读」会打断上一段，不会叠加。
- 暂停位置基于单个音频元素，切换会话会重新开始。
- 中文以外按「一串英文算一声」处理，长单词会整串读成一个音节。
