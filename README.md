# 哔哔啵啵朗读（dsh-bibibobo）

用 [bibibobo](https://github.com/hakihakii/bibibobo) 的锯齿波小人声，把 DeepSeek Harness 的回复念出来。可以随时暂停、继续、结束。

不是录音，不是 TTS 模型，是浏览器里实时算出来的波形——一条锯齿波加两个带通滤波器。

## 装

```bash
# 从 npm（发布后）
dsh plugin --profile desktop install dsh-bibibobo

# 或从本仓库目录
dsh plugin --profile desktop install /path/to/dsh-bibibobo
```

也可以在 **Plugins → Add plugin** 里选这个目录。

装完开个新会话，输入框上方会出现「🔊 朗读」。

## 用

| 按钮 | 作用 |
|---|---|
| 🔊 朗读 | 把最近一条已完成的回复念出来 |
| ⏸ 暂停 | 暂停，位置保留 |
| ▶ 继续 | 从暂停处接着播 |
| ⏹ 结束 | 立即停止并释放音频 |

朗读的永远是**最新一条已经完成的**回复。流式输出中的内容不会被读——边生成边读会让同一句话反复中断重来。

## 声音怎么来的

1. 一条抗混叠锯齿波（polyBLEP）当声带；
2. 两个状态变量带通滤波器捏出口型，五种口型就是五对共振峰频率；
3. 一个汉字一声，一串英文或数字一声；每个字用哈希算出固定的音高和口型，所以**同一个字永远是同一声**；
4. 标点管语气：问号尾音上扬，感叹号整句升高，省略号整句压低。

两套声线：大肥鱼（E5 G5 A5 B5 C6，共振峰 ×1.25）和路墨（D4 E4 G4 A4，共振峰 ×0.9）。

## 朗读前会清掉的 Markdown

代码块、行内代码、图片、链接地址、标题井号、引用符号、列表符号、强调记号都会被去掉，只留能念的文字。链接保留文字、丢掉地址。

回复超过 1200 字会截断，避免一次点击产生几分钟音频。

## 已知边界

- 只读**纯文本**部分。带工具调用和思维链的回复，只念最终文字。
- 同一时间只能有一段朗读。点「朗读」会打断上一段，不会叠加。
- 暂停位置基于单个音频元素；切换会话会重新开始。
- 中文以外按「一串英文算一声」处理，长单词整串读成一个音节。

```bash
node test/synth.test.mjs   # 合成器与原项目逐样本一致性
```

改了 `client.js` 里的合成器后请跑一遍测试。插件用 `link:` 方式安装时，改源文件刷新页面即生效，不需要重装。
